# Package index

## Functions

The functions built within this package to visualize and format
fisheries management data

- [`expand_status()`](https://sefsc.github.io/FishHist/reference/expand_status.md)
  : Expand regulations based on the management status field
- [`gantt_FMP()`](https://sefsc.github.io/FishHist/reference/gantt_FMP.md)
  : Gantt chart of FMPs
- [`plot_mcats_sector()`](https://sefsc.github.io/FishHist/reference/plot_mcats_sector.md)
  : Plot of management categories recorded under an FMP by sector
- [`plot_mcats_spp()`](https://sefsc.github.io/FishHist/reference/plot_mcats_spp.md)
  : Plot of management categories recorded under an FMP for all managed
  species
- [`plot_species_timeline()`](https://sefsc.github.io/FishHist/reference/plot_species_timeline.md)
  : Timeline of management types recorded for a species within a region
- [`process_closures()`](https://sefsc.github.io/FishHist/reference/process_closures.md)
  : Process and connect all closure-related management types for a
  species within a region
- [`tab_definitions()`](https://sefsc.github.io/FishHist/reference/tab_definitions.md)
  : Table of definitions provided under each Federal Registrar (FR)
  notice

## Datasets

Example processed analysis-ready Southeast Fisheries Management Dataset
that can be used for practicing use of the package’s functions

- [`fishhist`](https://sefsc.github.io/FishHist/reference/fishhist.md) :
