# FMP plot by sector

Percent of regulations by management type and sector (recreational vs.
commerical)

## Usage

``` r
plot_mcats_sector(data = fishhist, FMP_filter)
```

## Arguments

- data:

  default=fishhist

- FMP_filter:

  Filter to plot only a single FMP of interest.

## Value

A plot

## Examples

``` r
plot_mcats_sector(fishhist, FMP_filter="REEF FISH RESOURCES OF THE GULF OF MEXICO")

```
