# Plot of management categories recorded under an FMP for all managed species

Number of FRs published by management type and species

## Usage

``` r
plot_mcats_spp(data = fishhist, FMP_filter)
```

## Arguments

- data:

  default=fishhist

- FMP_filter:

  Filter to plot only a single FMP of interest.

## Value

A plot

## Examples

``` r
plot_mcats_spp(fishhist, FMP_filter="REEF FISH RESOURCES OF THE GULF OF MEXICO")

```
